# D-005 — M2 Decisions: Brief Understanding (FR-02, FR-03)

Status: APPROVED

Scope: Milestone M2 "Brief Understanding" (PRD FR-02, FR-03).

## Context & Objectives
Milestone M1 (Structured Project Data: Projects & Shots) is complete and verified (D-004).
Milestone M2 introduces brief ingestion and structured requirement extraction to eliminate fragmented production knowledge and provide the foundational creative direction for downstream change analysis.

## Core Entities (`contracts/data-model.md`)
1. `SourceDocument`:
   - `id`: stable string (`doc_...`)
   - `project_id`: FK to projects
   - `source_name`: string (e.g. "CyberPulse Creative Brief v1")
   - `content`: text (raw brief text or markdown)
   - `created_at`: timestamptz
2. `ProjectBrief` (Structured extraction):
   - `id`: stable string (`brief_...`)
   - `project_id`: FK to projects
   - `source_document_id`: nullable FK to source documents
   - `objective`: text
   - `visual_style`: text (e.g. "Realistic Cinematic Cyberpunk")
   - `lighting_mood`: text (e.g. "Moody cool blue lighting, wet asphalt reflections")
   - `characters`: JSON array of character specs (e.g. Aria identity, outfit, cybernetics)
   - `key_props`: JSON array of key objects/props (e.g. hexagonal data core)
   - `constraints`: JSON array of constraints/requirements
   - `unresolved_questions`: JSON array of ambiguities or items needing review
   - `review_status`: enum (`pending_review`, `approved`)
   - `created_at`, `updated_at`: timestamptz

## API Endpoints (`contracts/api-brief.md`)
- `POST /projects/{project_id}/brief/ingest`: Ingest brief text.
- `POST /projects/{project_id}/brief/extract`: Run structured extraction against ingested brief.
- `GET /projects/{project_id}/brief`: Get active brief and structured extraction.
- `PUT /projects/{project_id}/brief`: Update/approve structured brief (Human-in-the-loop).

## UI Specifications (`contracts/ui-brief.md`)
- Replaces "No brief yet" placeholder on `/projects/:id/overview` with active Brief Summary card.
- Dedicated Brief View / Editor (`/projects/:id/brief`):
  - Ingestion view: Paste raw brief text.
  - Review & Edit view: Structured form fields for visual style, characters, constraints, and unresolved questions.
  - Action button: "Approve Structured Brief" (sets status to `approved`).

## Demo Dataset
- Evaluates against the canonical CyberPulse V1 creative brief defined in `contracts/test-scenario.md`.
