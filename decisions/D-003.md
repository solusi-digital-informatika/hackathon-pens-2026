## Database & Data Model

- Table `shots`:
  - `id`: string (stable identifier, e.g. `shot_...` or UUID, immutable once created).
  - `project_id`: string (foreign key to `projects.id`, ON DELETE CASCADE, indexed).
  - `sequence_order`: integer (1-indexed order within the project).
  - `title`: string (1 to 100 characters, trimmed, required).
  - `description`: text (up to 1000 characters, optional, nullable).
  - `status`: string enum (`draft`, `in_progress`, `in_review`, `approved`), default `draft`.
  - `created_at`: timestamptz (UTC, auto-generated).
  - `updated_at`: timestamptz (UTC, auto-updated).
- Isolation: Application-level query scoping by `project_id`. An unknown `project_id` or `shot_id` returns 404.

## API Endpoints (`contracts/api-shots.md`)

- `POST /projects/{project_id}/shots`: Create a new shot. Auto-assigns next `sequence_order` if omitted. Returns `201 Created`.
- `GET /projects/{project_id}/shots`: List shots for a project, sorted by `sequence_order` ascending. Returns `200 OK` with items array and total count.
- `GET /projects/{project_id}/shots/{shot_id}`: Get single shot details. Returns `200 OK` or `404 Not Found`.
- `PATCH /projects/{project_id}/shots/{shot_id}`: Update title, description, status, or sequence_order. Returns `200 OK` or `404 Not Found`.
- `DELETE /projects/{project_id}/shots/{shot_id}`: Remove shot. Returns `204 No Content` or `404 Not Found`.
- Error envelope: Reuses standard error body shape from `api-projects.md` (`{"error": {"code": "...", "message": "...", "fields": [...]}}`).

## UI Specifications (`contracts/ui-shot-board.md`)

- Screen `/projects/{id}` Overview Header & Shot Board:
  - Replaces "No shots yet" placeholder with the active Shot Board view.
  - Grid / storyboard card display showing: sequence badge (e.g. `Shot #1`), Title, Description, and dual-coded Status (`[Draft]`, `[In Progress]`, `[In Review]`, `[Approved]`).
  - "Add Shot" button opening modal / creation form.
  - Edit and Delete actions per shot card.
  - Empty state when no shots exist: "No shots yet. Add a shot to start planning." with primary "Add Shot" action.
  - Loading, error (400 inline, 500 banner), and success states.
